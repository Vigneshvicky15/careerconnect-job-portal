# 💼 CareerConnect – Job Portal

A full-stack MERN job portal that connects recruiters and job seekers through a secure and responsive platform.

## 🚀 Features

* User Authentication
* Recruiter Dashboard
* Candidate Dashboard
* Job Posting
* Job Search
* Apply for Jobs
* CRUD Operations
* Responsive Design

## 🛠️ Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* JWT Authentication
* Tailwind CSS
